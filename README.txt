# My Lifestyle Tracker

PWA personale in italiano, responsive per iPhone.

## Avvio
Apri `index.html` in un browser per provarla. Per installarla come app su iPhone e abilitarne l'uso offline, pubblica la cartella su un hosting HTTPS (ad esempio GitHub Pages), poi apri l'indirizzo in Safari > Condividi > Aggiungi alla schermata Home.

## Dati e privacy
I dati vengono salvati nel localStorage del browser sul dispositivo. Esporta periodicamente il backup JSON da Profilo. Non c'è sincronizzazione cloud né collegamento ad Apple Salute, Fitdays o Lyfta.

## Archivio alimenti
I nomi forniti sono già presenti. I valori nutrizionali non sono stati inventati: importa un CSV con intestazione `alimento,kcal,grassi,carboidrati,proteine`, con valori per 100 g. Puoi anche modificare i valori dal pannello Cibo/Profilo.
